01 TRANSLATION AI

AI That Translates —
The Encoder–Decoder Model

Encoder–Decoder Model

Because word order differs across languages, translation isn't just word-by-word. Instead, the model first "digests" the whole sentence into a single meaning, then builds the output from that.

The input sentence is turned entirely into numbers (a vector) that capture its meaning, and the output words are generated from that vector.

In this simplified encoder–decoder diagram, the meaning vector is a numeric summary of the whole sentence—not a translation of any single word. It carries information such as who did what to whom, allowing the decoder to rebuild the sentence in a different word order.

03 ATTENTION

Meaning Depends
on Context

Attention

"Apple" can mean a fruit or a company. A word's meaning isn't fixed by itself — it's shaped by the words around it.

Attention updates a word's vector using the vectors of the surrounding context words. Here, that's shown as Apple's point shifting toward the fruit or tech cluster depending on the sentence.

Simplification: a real Transformer doesn't "look up a map" like this — it blends the actual words in that one sentence. But real contextual embeddings do show the same effect: the same word lands in noticeably different places depending on meaning.

06 EMBEDDINGS

From a Sentence
to 512-D Vectors

BPE Tokenization + Embedding Lookup

First, BPE splits the sentence into reusable subword tokens. Each token is represented conceptually as a one-hot row with about 37,000 possible positions.

One matrix multiplication selects a learned 512-number vector for every token. There is no hidden layer or activation function inside the Input Embedding block.

In code this is implemented as a fast row lookup, but it is mathematically equivalent to the matrix multiplication shown here.

11 DOT PRODUCT

A Score for
Vector Similarity

Similar Direction → Larger Dot Product

Words with related meanings tend to point in similar directions in an embedding space. Their dot product is therefore large.

When two word vectors point in very different directions, their dot product becomes small—or even negative.

For this intuition, the vectors are normalized to the same length. Dot product measures directional alignment, not literal distance between the arrow tips.
Compare the angle — The closer the directions, the larger the dot product.
