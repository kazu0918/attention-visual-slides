22 MULTI-HEAD ATTENTION

Now Run Attention
in Parallel

One mechanism, several learned views

So far, we have followed one Attention(Q, K, V) operation from its inputs to a contextualized output.

Multi-Head Attention repeats that operation in parallel. Each head receives its own learned projections of Q, K, and V, so it can form a different attention pattern.

The heads are not assigned fixed jobs by hand. During training, each projection learns a useful way to view the same sequence.
