19 USING THE WEIGHTS

Move Each Token
Toward Its Context

A weighted mixture of Value vectors creates a new representation

The scores decide how much information to collect from each word. Important words pull more strongly; unrelated words contribute only a little.

The result is usually not another existing word vector. It is a new point that combines the information needed for this sentence.

Attention does not simply add every vector equally. After softmax, the weights sum to 1, producing a weighted mixture: output = Σ attention weight × Value vector.
The same starting vector moves in two different directions.
FRUIT CONTEXT“I ate a juicy apple.”
juicy 0.48apple 0.34ate 0.09others 0.09
appleupdated =0.48 × juicy vector + 0.34 × apple vector
+ 0.09 × ate vector + 0.09 × others
COMPANY CONTEXT“I bought an Apple laptop.”
laptop 0.52Apple 0.30bought 0.13others 0.05
Appleupdated =0.52 × laptop vector + 0.30 × Apple vector
+ 0.13 × bought vector + 0.05 × others
Not replacement—contextualization.The updated vector does not become “juicy” or “laptop”; it becomes an apple representation influenced by those words.
