06 EMBEDDINGS

From a Sentence
to 512-D Vectors

BPE Tokenization + Embedding Lookup

First, BPE splits the sentence into reusable subword tokens. Each token is represented conceptually as a one-hot row with about 37,000 possible positions.

One matrix multiplication selects a learned 512-number vector for every token. There is no hidden layer or activation function inside the Input Embedding block.

In code this is implemented as a fast row lookup, but it is mathematically equivalent to the matrix multiplication shown here.
One horizontal operation — Token matrix × Embedding matrix = vector sequence
