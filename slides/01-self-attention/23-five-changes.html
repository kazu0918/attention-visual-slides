23 MULTI-HEAD ATTENTION

What Changes
with Multiple Heads?

Five differences from the single-head explanation

The Attention calculation itself stays the same. What changes is how its inputs are prepared, repeated, and combined.

Each head sees the same sequence through a different learned projection.
Single head → Multi-head - the same Attention operation becomes a parallel pipeline.
  1. 01 Run in parallel

    The usual Attention operation runs as multiple heads.

  2. 02 Add separate projections

    The same H becomes different Qi, Ki, Vi through each head’s learned parameters.

    H → Qi, Ki, Vi
  3. 03 Use smaller dimensions

    Each head’s Qi, Ki, Vi is lower-dimensional.

    dhead = dmodel / h
  4. 04 Concatenate the heads

    Keep each result, then join them side by side.

    Concat(head1, …, headh)
  5. 05 Apply the final Linear

    WO mixes the concatenated head outputs into one result.

    Concat(…)WO
