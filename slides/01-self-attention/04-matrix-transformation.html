A Matrix Transforms

A Linear Algebra View

A point on a coordinate plane is a vector. Multiplying it by a matrix transforms it into a new vector — shown as the point landing at a new position.

This is one way to view what we want for Apple: start with the same context-free vector, then transform it into a representation that includes the sentence's meaning.

The matrix below is an intuition-building 2D example. In a Transformer, attention computes the context-dependent mixing weights from the sentence itself.
