Recurrent neural networks, 1997–2016

Before 2017, sequence problems ran on RNNs — in practice on their gated descendants, LSTM and GRU. The paper's own opening sentence calls them "firmly established as state of the art".

machine translation language modelling speech recognition summarisation handwriting

The idea is a running memory. Read one token, update a hidden state, carry it forward. Everything the network knows about the sentence so far lives in that one vector.

LSTM (Hochreiter & Schmidhuber, 1997 — reference [13] in today's paper) added gates so the state could carry information further before it decayed. It made long sentences workable. It did not change the shape of the computation, which is what the next two slides are about.
Step 0 — The hidden state starts empty. Nothing has been read yet.
