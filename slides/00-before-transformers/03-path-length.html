How Far Must

Long-range dependencies and path length

To connect two words, an RNN has to push information through every step in between. Twenty words apart means twenty transformations, each one a chance for the signal to decay or be overwritten.

Attention connects any two positions in one operation, whatever the distance. That is the second column of Table 1, and it is a separate argument from parallelism — don't merge them when you present.

LSTM gates mitigate this; they don't remove it. The path is still there, just better insulated. §4: "The shorter these paths between any combination of positions in the input and output sequences, the easier it is to learn long-range dependencies."
